# PocketBoost starter

A beginner-friendly, static Progressive Web App (PWA) prototype. It includes:
- Caption starter
- Hashtag ideas
- Discount calculator
- Profit calculator
- WhatsApp promotional message writer

## Run it on your computer
1. Unzip this folder.
2. Open `index.html` in a modern browser to test the tools.
3. For installability/offline support, serve it over HTTPS (or localhost). Opening the file directly will not enable the service worker.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new **public** repository, e.g. `pocketboost`.
3. Upload `index.html`, `manifest.json`, `sw.js`, and `icon.svg` to the repository root.
4. Open repository **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. Open the provided HTTPS address on your phone.
7. On Android, use the browser menu → Install app / Add to Home screen. On iPhone, use Safari → Share → Add to Home Screen.

GitHub Pages documentation: https://docs.github.com/en/pages

## Before launching publicly
- Replace the working name PocketBoost if desired; check name/trademark availability first.
- Add a contact email, privacy policy, terms, and clear disclaimers.
- Test on several Android and iPhone screen sizes.
- Ask 5–10 small-business owners to test and report confusing parts.
- Do not add advertising or collect personal information until the required policies, consent, and disclosures are in place.

## Monetization plan
1. Start free and validate that people return to use the tools.
2. Create genuinely useful paid template packs or downloadable resources.
3. For payments, use a verified Indian payment provider/payment link or a transparent manual UPI option for early tests. A payment link/provider generally settles to your verified bank account, not a separate Google Pay wallet balance.
4. Add recurring billing only after users demonstrate demand.
5. Treat ads as a later step; ad networks review sites/apps and may require eligibility and policy compliance.

## Important
This prototype stores no user accounts and sends no data to a server. It does not contain a payment system, AI model, analytics, or advertising. It is a starting point, not a finished commercial product.
